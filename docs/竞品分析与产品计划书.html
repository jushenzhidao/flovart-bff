1产品定位与核心优势

oneArt 是一款节点式（Node-based）AI 视觉创作平台：用户在无限画布上创建图片 / 视频节点，通过连线组织"生成 → 编辑 → 加工 → 分镜"的完整生产流水线，覆盖从灵感到成片的全流程。

差异化核心：节点式工作流，不只是"一堆按钮"
主流竞品的 AI 编辑均为"单图单工具"模式——用户需要在多个页面间来回导出导入。oneArt 将全部能力沉淀在一张无限画布上：多节点连线、批量执行、自动分组、操作可重跑（配方化），真正面向"批量生产"而非"单次尝鲜"。这是与即梦 / Canva / 美图类产品的代际差异，对标国际新兴的 Krea / Weavy 形态并完成本土化超越。
全链路一站式
22 种图片 AI 工具 + 视频生成 + 视频加工套件 + 智能分镜模板 + 自定义工具栏，图片到视频无需切换平台。
网关化计费体系
全站调用统一经 AI 网关按量计费，账目清晰、可审计、可对账，适配平台运营与渠道合作两类场景。
多上游模型接入框架
已打通 16+ 上游模型通道，能力级开关运行时可配——合作方的自有模型可快速接入，天然适配商务共建。
私有化与可集成
容器化交付，支持私有化部署；提供标准化 API，可作为企业内容生产的底层引擎。

总结论：国内头部产品（即梦 / 可灵）强在模型与流量、弱在生产组织形态；国际新兴工具（Krea、Lovart）验证了"画布 / Agent"形态是 AI 生产力的正确方向，但前者缺本土化、后者 Agent 黑盒不可控且商务开放度低。oneArt 站在两者交叉点：用节点工作流组织国内一流模型能力，覆盖"图 → 视频 → 分镜成片"的完整生产链，并以网关化计费 + 多上游 + 私有化构建商务合作 uniqueness。

5后续上新计划（Roadmap）

近期 未来 1 ~ 2 个月
  • 涂鸦生图：画布内嵌画板，简笔涂鸦 + 描述词一键生成成图（草图 → 成品）
  • 局部重绘强度可调：0.3 ~ 1.0 重绘幅度滑杆，精细控制修改范围（对标即梦）
  • 一键主体选区：AI 自动识别主体生成蒙版，替代纯手涂
  • 多尺寸智能适配：裁剪 + 扩图组合，一键产出多平台尺寸（对标 Canva Magic Resize）
  • 视频渠道扩容：接入更多视频生成上游，提升可用性与性价比
中期 3 ~ 6 个月
  • 批量电商商拍：多 SKU × 多背景 × 多尺寸矩阵式一键出图
  • 画质修复套件 2.0：老照片修复 + 上色 + 超分一体化流水线
  • 开放 API：将节点生产能力以标准化 API 输出，供企业系统集成
  • 实时画布（评估中）：涂鸦即所得的极速生成体验，待极速模型渠道就绪后上线
远期 6 个月以上
  • 团队协作：多人画布、云空间、素材库共享、角色权限
  • 模型接入市场：合作方模型自助上架，能力分成生态
  • 多端覆盖：移动端 / 小程序轻量创作入口

6合作模式与价值主张

渠道合作
合作接入即走网关计费：按实际调用量结算，明细可查、可审计、可对账，平台无需垫付算力成本，双方账目清晰。
模型共建
多上游接入框架支持合作方自有模型快速上架，能力级开关灰度放量，共同服务终端客户。
私有化交付
容器化部署，可交付至合作方自有环境，数据不出域，适合电商、 MCN 、企业内容团队。
OEM / 白标
产品能力可整体输出，合作方以自有品牌运营，oneArt 提供持续版本迭代与上新支持（见 Roadmap）。
一句话价值主张：把即梦们的"单点工具"升级为 Krea 们的"生产流水线"，并且是国内唯一支持网关化计费 + 自有模型接入 + 私有化三者兼备的节点式 AI 创作平台。
